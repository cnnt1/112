# 模块边界

- 设备控制负责设备通信、命令校验和错误转换。建议接口为 `read_status(device_id)` 和 `execute(device_id, command)`。模拟设备与后续设备适配器遵循同一接口。
- 自动化负责触发、条件判断、步骤顺序和运行记录。首版调用设备控制接口，记录运行 ID 及每步结果。命令超时时记录结果未知并停止后续动作，避免重复下发可能已经执行的命令。
- 清洁剂研发负责实验记录、样品编号和评估结果。首版独立维护，后续如需关联运行记录，可引用实验 ID。

首版依赖方向为 `automation → device-control`。模块测试随实现放在对应项目的 `tests/`，跨模块测试放在根目录的 `tests/integration/`。语言、协议和硬件随首个实现确定。
